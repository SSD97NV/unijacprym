# unijacprym

This repository is the computational supplement to Junming Gao's master's
thesis *Canonical Rings of Compactified Universal Jacobians and a
Contact–Fitting Modification at a Genus-13 Prym-Torsor Boundary*. It contains
bounded Lean and Singular certificates for explicit algebraic calculations in
the local part of the thesis. It is not the source repository for the thesis
and does not formalize its geometric main theorems.

## Mathematical content

The four Lean modules check:

- the universal-node matrix factorization and the ideal generated by the
  entries of its displayed presentation matrix;
- the contact-defect relation, the identity
  $I_m^2=(a)\mathfrak d_m$, and the corresponding even-power identity;
- the two conversions between degree and Euler-characteristic congruences;
- the rational Schur-complement identities for the central and general
  retained curves.

The Singular script checks the three saturated affine-chart presentations,
the odd-square identity, and the chain of contact ideals for contact orders
$1\leq m\leq 6$. See [THESIS_MAP.md](THESIS_MAP.md) for the exact Lean
declaration names, the corresponding thesis statements, and the limitation of
each certificate.

## Software environment

- Lean 4.32.2, selected by `lean-toolchain`;
- Mathlib 4.32.2 at revision
  `905b95818eb32af7874a58b427f50c1711a5e96c`, with the complete dependency
  graph recorded in `lake-manifest.json`;
- Singular 4.4.1 for the frozen release report. The GitHub Actions runner uses
  the compatible Singular 4.3.2 package supplied by Ubuntu 24.04 and evaluates
  the same explicit assertions.

Git, [Elan](https://github.com/leanprover/elan), and Singular must be installed
before running the checks.

## Frozen verification

The computational baseline used while preparing the thesis is commit
[`1c22cfa250e25a3d90be7f46be22b99a00c3961c`](https://github.com/SSD97NV/unijacprym/commit/1c22cfa250e25a3d90be7f46be22b99a00c3961c).
To reproduce that state from a clean checkout, run:

```sh
git clone https://github.com/SSD97NV/unijacprym.git
cd unijacprym
git checkout --detach 1c22cfa250e25a3d90be7f46be22b99a00c3961c
lake exe cache get
sh verify.sh
git diff --exit-code
```

Do not run `lake update`: the committed `lake-manifest.json` is part of the
frozen dependency state. The final command confirms that verification has not
modified a tracked file. The expected Lean axiom output is recorded in
`verification/AXIOM_REPORT.txt`.

An archival release tag will replace the baseline hash in these instructions
only after the release has been created and checked. A Zenodo DOI will be
added only after Zenodo has processed that release.

## What is not formalized

The certificates verify the displayed matrix, ideal, congruence, power,
intersection, saturation, and elimination identities within the assumptions
stated in their source files. In particular, they do not prove exactness or
depth of the universal-node module, the classification of reflexive modules,
the geometric interpretation of a Rees algebra or blow-up, Mumford
intersection theory, stack algebraicity, the existence of a good moduli
space, fixed-stack descent, scheme-theoretic-image descent, algebraization of
the pairing centre, component incidence, scalar-gerbe descent, or the
canonical-ring results. The Singular checks for $1\leq m\leq6$ are finite
computational samples; the theorem for arbitrary contact order is proved in
the thesis.
